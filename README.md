AI Invoice Manager - "Jarvis"
🚀 Panoramica del Progetto
Questo progetto, sviluppato da un Ingegnere Informatico, nasce dall'esigenza di automatizzare il processo di gestione contabile domestica. Il sistema, soprannominato Jarvis, utilizza l'Intelligenza Artificiale per "leggere" fatture in formato PDF e integrare i dati direttamente in programmi gestionali.

🛠️ Caratteristiche Tecniche
Analisi PDF Intelligente: Utilizzo di PyPDF2 e Regex per l'estrazione mirata di fornitori (ENI, GORI, ENEL), consumi (kWh) e importi.
Interfaccia Vocale: Integrazione di pyttsx3 per fornire feedback vocali all'utente durante l'elaborazione.
Gestione Database: Scrittura automatizzata in file .csv sincronizzati con software di bilancio familiare.
AI-Assisted Development: Il codice è stato ottimizzato utilizzando LLM (Gemini) per il debugging rapido e la generazione di moduli efficienti.
💻 Stack Tecnologico
Linguaggio: Python 3.x
Librerie: os, re, csv, shutil, datetime
Ambiente: Visual Studio Code con gestione di ambienti virtuali (.venv)
